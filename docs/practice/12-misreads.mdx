# Misreads and mastery

**Which Gexbot capability this is.** The catalog of imported mistakes, plus a capstone that writes no entry.

**What you will be able to do.** Pair each guardrail with its misread, and annotate a session with forced-flow sentences only.

**What you already need.** The whole book, including the `Structure:` field and the S-reads from [Chapter 9b](/docs/practice/09b-structure-and-gexbot).

## Imported-tool misreads

An **imported-tool misread** is bringing another product’s object into Gexbot and treating it as the same measurement. Chapter 1 named the cousin families. Here is the same cut as a recap, not a first introduction.

| What people bring in | Gexbot cut |
|---|---|
| Unsigned call wall = fade | Classic owner is **unknown** |
| Futures-native “the level” | ES_SPX / NQ_NDX is converted leftover |
| Premium sweep = huge DEX | Leftover weighted by schoolbook sensitivities; a cheap 0DTE can dominate |
| Open/close tag | Gexbot does not split |
| Full-book charm pin at 10:00 ET | Residual-only, last-hour family |
| Green = bullish | Call-sided leftover; on SPX often sold (*folklore*) |
| Named charting level = Gexbot node | Structure is observed on the futures; nodes are converted index strikes |

## Guardrail pairs

A **guardrail** is a sentence that keeps a later chapter from undoing an earlier one. You already met each pair in the chapter that owns it. This table only repeats. Each misread is a guardrail read backwards: the certainty it borrows is the one the guardrail withholds.

| Misread | Guardrail |
|---|---|
| DEX bar = buying still to come | Already hedged versus pending |
| “Dealers must…” from Classic | Unknown; “must” is mandate only |
| Customer “forced” to dump | Incentive, never forced |
| Quiet ladder = nothing traded | Pressure: none (cancelled two-way) |
| One desk will do X | Dealer is a population |
| Self-hedged customer ignored | Two hedgers ≈ no net forced flow (*inferred*) |
| Tick-by-tick chase | Hedge in bands (*market-general*) |
| Wall as a fact | Walls are hypotheses |
| Falling-vol map on a rising-vol tape | Vol regime governs the customer channel |
| ES print = the hedge | You cannot identify it. Conversion limit. |
| SPX 0DTE resolution on SPY | Settlement styles differ |
| 15:50 net on a 09:35 fill | Labeling leak |
| Overnight high is a State wall at 09:31 | No leftover yet; Classic open interest is unknown |
| Futures print confirms the DEX bar | Different objects. Never “the dealer.” |
| Alert during a sweep is the S2 read | The ping is the touch. Fill Structure, node, pressure, both falsifiers |
| Node “at” a level three points away | Strike spacing: a node is a bucket, not a tick. Write the width down |
| Three orderflow bars = three confirmations | Same-print stacking. One print, three cuts |
| Ladder grew, so someone bought | Re-marking. Check Orderflow for the same minute |
| Two opposite bars = buyers versus sellers | Multi-leg structure. Read together; convexity cancels |
| No node, so nothing there | Partial picture. Absence of a node is not absence of pressure |
| VIX fell, so falling vol | VIX is thirty-day. Intraday regime comes from the skew dots (H12) |
| Open-interest mountain at a level = wall | Grade A: location, owner unknown. Wait for Grade C |
| First big bar at 09:33 = day-type | An event, not a sequence. H3 needs thirty to sixty minutes |
| Daily level decides this morning | Full-group sentence. This morning is a latest-group sentence |

## Mastery rubric

You can:

1. Name the **2×2** or say you cannot.
2. Name the **clock family**.
3. Name the **conversion limit** (ES_SPX / NQ_NDX).
4. Write a **forced-flow sentence** or **unknown**.
5. Name a **falsifier** in both languages: a price observation and a leftover observation.
6. Name the **structural location** (`Structure:`), or write that you are sitting a Gexbot-only line.

## Capstone

A **capstone** here is one annotated session, not a trade.

Annotate one full cash regular-hours session on **ES** and one on **NQ**. No entry. Every annotated node carries:

```
Structure:
actor · pressure · trigger · direction · venue
Falsifier:
  price —
  leftover —
```

or `UNKNOWN`.

The `Structure:` field turns those annotations into S-form reads. It does not introduce an entry. If you write an entry, you left the course.

## Summary

Each misread is a guardrail read backwards. Naming the misread without the guardrail is another misread. Mastery is the pair — cell with clock, conversion with its limit, pressure sentence with its falsifier in both languages — not a longer list of objects and not a locked edge.

## Newcomer questions

1. **H4 names a wall candidate at a Grade C leftover, and the guardrail says walls are hypotheses.** Which sentence do you write? The candidate and its falsifier. Grade C licenses a pressure word as a hypothesis, not a fact. “The wall will hold” is the misread of both lines at once.
2. **“No node, so nothing there” and “there is always a strike near any level.”** Which refusal? Absence of a bar that stands out on today’s ladder is not absence of pressure; presence of a neighbor bar is not confluence. Write “no Gexbot object here,” or wait.
3. **VIX is down and the skew dots are flat.** Falling-vol map? No. Intraday regime is the dots (H12). VIX is a thirty-day quote. Stand down on wall versus fuel until the dots move.
