# Heuristics as reading

**Which Gexbot capability this is.** None new. These are naming drills on Classic, State, Orderflow, and clocks.

**What you will be able to do.** Walk five reads — this book numbers them H1 through H5 — each with a pressure word and a hedge-chain link. Not a system. No hit rate.

**What you already need.** Chapters 1–7. If a stop or target is not in the docs, it is **inferred**.

A **heuristic** in this book is a **naming drill**: practice saying what you are looking at. It is not an order to send.

**Default clocks.** Residual: 09:30–16:00 Eastern. Early regular-hours map to ES or NQ: 09:29–11:00. Last-hour family: 15:00–16:00. Do not pool them.

**Stand down** when Orderflow is two-sided noise, leftover is too thin to name a major, you are using the falling-vol map on a rising-vol tape, you used full-book zero gamma for a 0DTE scalp, or you treated converted walls as exchange volume.

## H1 — SPX GEX-orderflow pivot (*folklore*)

This drill sits **GEX orderflow** on SPX. Hedge-chain link 1 (the print), plus link 4 if you add convexity.

Pressure is **mandate** on absorb. Owner still needs the 2×2. Classic cannot supply it.

The read: a standout plus GEX-orderflow bar into a call-heavy node is a **local-top** *candidate* on SPX. The mirror minus bar is a local-bottom candidate. The read is off when the docs’ “SPX trading like SPY” (VIX above 20) *folklore* applies, or when convexity shows the bar was **long calls**.

Forced-flow sentence: dealer absorbed call-sided leftover · mandate · print · *unknown direction until the 2×2* · ES.

## H2 — Name the plus-DEX (expansion versus pin)

This drill pairs **DEX orderflow** with **convexity orderflow**. Link 1, then the sign of link 4.

Pressure: mandate on the dealer mirror; customer incentive differs by cell.

The read: plus DEX and plus convexity → **long call** (expansion). Plus DEX and minus convexity → **short put** (pin). Mirror the signs for minus DEX. Name the 2×2 cell or do not name the print.

<TermFirst id="h2" />

## H3 — Fear tape versus grind tape

This drill sits a **sequence** of convexity-orderflow bars, plus the nets. It is a **day-type** filter. It is not an entry.

Pressure: aggregate pending gamma lean (mandate) plus customer vol bid or offer (incentive).

The read: many small plus-convexity bars → fear / vol-bid. Many small minus-convexity bars → grind / premium-sale (*folklore*). Do not name the day at 09:35 from one spike.

<TermFirst id="h3" />

## H4 — Walk into a stack

This drill sits State: options profile, DEX, and convexity. Link 4 and customer incentive.

Pressure: customer **incentive** (vol regime). Dealer **mandate** on the mirror. Apply the vol flip from Chapter 4.

The read: in falling vol, approach a customer-long node → stall *candidate*; approach a customer-short node → continuation *candidate*. Do not use a stack that printed *after* the touch — that is a labeling leak.

Walls are hypotheses. Chapter 9 will test them with **acceptance through** the node.

<TermFirst id="h4" />

## H5 — Last-hour 0DTE short-convexity magnet (*beta*)

This drill sits the clock family from Chapter 7. Hedge-chain **link 5**, not link 4.

Pressure: dealer **mandate**, clock or vol, residual-only. Off if net minus-vanna is not “extreme” by the docs’ discretionary $800 million / $1000 million SPX note (*folklore*).

The read: pin or attract toward 0DTE minus-convexity. Different family from H1–H4. Flow dies if the node goes at-the-money.

<TermFirst id="h5" />

## Summary

Each heuristic is a naming drill. Each states which pressure it relies on. None is locked doctrine. Stand down when the clock family, the vol regime, or the leftover thickness does not support a name.

## Newcomer questions

1. **Which heuristic is an entry?** None, as a system. H3 has no entry at all.
2. **Can I use H5 at the open?** No. Different clock family.
3. **Does H1 work on NQ?** Only if you rename the claim. It is SPX folklore.
