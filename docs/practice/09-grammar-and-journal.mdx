# Grammar and journal

**Which Gexbot capability this is.** The structural grammar for a note — not a robot.

**What you will be able to do.** Write one journal line that includes a forced-flow sentence, or write “unknown” and stand down.

**What you already need.** Chapters 1–8.

## Picking a window

1. Name the **claim**: early RTH map (09:29–11:00) vs full RTH residual vs last-hour magnet. Do not pool them.
2. Need **enough residual** to name majors (knowability).
3. 0DTE / latest is the default lens. Next for roll. Full only as overnight context.
4. Last-hour vanna/charm is a **different window** with a different object (pin).

## Minimum agreement before you name a read

- The **2×2 cell** (DEX × convexity), or do not name the print.
- **Where spot is** vs the relevant node (OP / DEX / convexity / latest zero-gamma).
- The **vol regime** before you call a node a wall or fuel.
- Prefer a **sequence** (H3) for day-type, then an **event** (H2) or a **touch** (H4). A single meter is not an entry.
- A **pressure** word: mandate / incentive / none / unknown.

## Stop logic (*inferred* grammar)

Stops attach to **Gexbot objects**, not to a round number:

- Wall / pin: **acceptance through** the named node.
- Fuel / expansion: **failure to take** the node, or reclaim through the long-option strike.
- Do not use a generic ATR stop unless you can map that width onto a named Gexbot distance — usually you cannot, then **do not trade it**.

## Target logic (*inferred* grammar)

- Pin / short-convexity / short-put: the target **is the node**.
- Expansion / long option: next opposing stack or air until a −convexity / opposite-DEX node. Scaled exit, not a heroic hold.
- Last hour: magnet strike. If you still hold an open-window expansion target into 15:30, you changed families without saying so.

## Journal line

```
Clock family:
Plan / screen:
2×2 cell (or “cannot name”):
Node:
Vol regime:
Forced-flow sentence:
  actor · pressure · trigger · direction · venue
  or UNKNOWN
What the screen does not show:
Falsifier:
```

No dollar PnL. No “trade this.” The line is a read.
