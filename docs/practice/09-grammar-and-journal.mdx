# Grammar and journal

**Which Gexbot capability this is.** The structural grammar for a note — not a robot.

**What you will be able to do.** Write one journal line that includes a forced-flow sentence, or write “unknown” and stand down.

**What you already need.** Chapters 1–8. You already have the 2×2, clock families, vol regime, the four pressure words, and the rule that a Gexbot ping is a touch, not a name.

## Picking a window

Name the **claim** before you name the node.

Early regular-hours map (about 09:29–11:00) is not the same claim as full-session leftover, and neither is the last-hour magnet. Do not pool them.

You need **enough leftover** to name majors. That is **knowability** from Chapter 7.

0DTE / latest is the default lens. Next is for the roll. Full is only overnight context.

Last-hour minus-vanna and charm are a **different window** with a different object (a pin). If you still hold a morning expansion target into 15:30, you changed families without saying so.

## Minimum agreement before you name a read

You need all of these, or you stand down. Each missing item is a place the read can be wrong without your knowing it:

- The **2×2 cell** (DEX sign times convexity sign), or do not name the print.
- **Where the index is** versus the relevant node (options profile, DEX, convexity, or latest zero-gamma).
- The **vol regime** before you call a node a wall or fuel.
- Prefer a **sequence** (H3) for day-type, then an **event** (H2) or a **touch** (H4). A single meter is not an entry. The ping Chapter 8 called an **alert** is that touch arriving. It does not name the node.
- A **pressure** word: mandate, incentive, none, or unknown.

## Stop logic (*inferred* grammar)

Stops attach to **Gexbot objects**, not to a round number.

For a wall or pin thesis: the falsifier is **acceptance through** the named node. Price trades through that strike and **stays**, rather than wicking. The docs do not state the grain. The idea is inferred grammar.

<TermFirst id="acceptance-through" />

For a fuel or expansion thesis: the falsifier is **failure to take** the node — the index cannot hold through it — or a reclaim back through the long-option strike.

<TermFirst id="failure-to-take" />

A generic average-true-range stop has no relation to the read. If price takes it, nothing the screen said has been falsified; you were stopped by a width, not by a leftover object changing. Use one only if you can map that width onto a named Gexbot distance. Usually you cannot, and then the honest line is **do not trade it**. This book is a reading course.

A **falsifier** is the observation that would make you withdraw the read. Write it before the session walks.

<TermFirst id="falsifier" />

## Target logic (*inferred* grammar)

For a pin, short-convexity, or short-put cell: the target **is the node**.

For expansion or a long option: the next opposing stack, or open air until a minus-convexity or opposite-DEX node. A scaled exit, not a heroic hold.

Last hour: the magnet strike. That is a different family.

## Journal line

A **journal line** is a written read. No dollar profit-and-loss. No “trade this.”

```
Clock family:
Plan / screen:
2×2 cell (or “cannot name”):
Node:
Vol regime:
Forced-flow sentence:
  actor · pressure · trigger · direction · venue
  or UNKNOWN
What the screen does not show:
Falsifier:
```

<TermFirst id="journal-line" />

If you cannot name the 2×2, write “cannot name” and stand down. If the screen cannot show the owner, write **unknown**.

If an alert fired and you cannot fill the cell, the node, the vol regime, or the pressure word, write “cannot name” or **unknown** and stand down. The ping was the clock. It was not the read.

A max-change strike (H10) is the same kind of object: a location until State names the owner. Do not put the ping or the redraw in the **Node** field as if either were the thesis.

## Summary

A missing field is not a partial read. It is a stand-down, because the missing field is usually the owner, the regime, or the cell — the one that would have made the sentence honest. The journal line is the read. An alert times a touch; it does not fill the blank.

## Newcomer questions

1. **The ping fired and I have the node but not the 2×2.** Do you write the line? No. Write “cannot name” and stand down. The ping was the clock. The missing cell is the reason the line does not exist.
2. **Can I put a max-change strike in the Node field?** No. Max-change is a location until State names the owner. Putting the redraw in Node treats the attention marker as the thesis.
3. **I have actor, pressure, and venue, and I am guessing the trigger.** Write unknown. A guessed trigger is an assumed hedge clock. The line without it is shorter and honest.
