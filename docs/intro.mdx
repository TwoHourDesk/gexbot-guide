# How to use this book

**Which Gexbot plan this is.** None yet. This page is the contract with the reader.

**What you will be able to do.** Open Chapter 1 knowing what this wiki is, what it is not, and which words this book uses for evidence and pressure.

**What you already need.** You can follow an NQ or ES chart. You do not need to have traded an option.

Everyone starts at [What Gexbot is](/docs/plans/01-what-gexbot-is). There is no five-chapter options pre-course. When a screen needs a schoolbook word, a **Needed to read this screen** box defines it, then the chapter returns to the Gexbot object.

## Information layer

Gexbot answers: *who is stuck with which greek, where, so far today.* It does not replace the futures tape. It is not a signal machine. It is not locked edge. It is not a color-rule cheat sheet.

This wiki does not write a robot, a hit rate, or a dollar PnL. Part B heuristics, when they appear, are **naming drills**.

Use them precisely. A bar on the screen is **observed**. A hedge you did not see is **inferred**. Ownership on Classic is **assumed** until State classifies it.

## Four pressure words

These are the book’s most important vocabulary after the Gexbot terms. They are taught on the screens that own them; here they are only named.

- **Mandate** — a dealer book runs delta-neutral by policy. This is the only flow the book may call **forced**.
- **Incentive** — the customer is not obliged to act. Write **incentivized**, never forced.
- **None** — cancelled two-way volume. No residual, no node, no pressure.
- **Unknown** — Classic OI and volume. The location is real; the owner is not visible.

“Must” is reserved for mandate. Never write “dealers must buy” from a Classic bar. Write “if the usual ownership shortcut holds, dealers would buy.”
