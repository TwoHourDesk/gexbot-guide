# Distinctions

Contrast **families of measurement**, not competing trade systems. A well-known tool may be named once so you can place the family. Never import that tool’s named levels or setups.

## Textbook dealer gamma

Dealers short gamma chase; dealers long gamma fade. Gexbot **keeps this polarity**. It adds a **customer** book: State and Orderflow report the customer sign. Docs treat a dealer-only map as half the picture. The customer channel is **incentive**, not mandate.

## Unsigned GEX maps

OI × gamma. “The GEX map.” Zero-gamma flip. Call wall / put wall as if ownership were known. Closest Gexbot cousin is **Classic**. WhoMustAct on Classic is **unknown**. State and Orderflow reject the unsigned-owner shortcut.

## Futures-native gamma products

Gamma computed on ES/NQ (sometimes RTY), often with pre-drawn levels. Gexbot’s ES/NQ is `ES_SPX` / `NQ_NDX`: a **multiplier conversion of leftover index options**, not CME volume or aggressor truth. The hedge may land in ES/NQ; the print did not happen there. Leftover QQQ (or SPY) options are a different pile.

## Premium / sweep flow tools

Debit-credit tapes, often with open vs close. Gexbot is **greek-weighted residual**. It does **not** split open from close. A large debit is not a large DEX print. A cheap 0DTE can dominate.

## Futures structure versus Gexbot nodes

Swing highs, range breaks, sweeps, gaps, and VWAP are **observed** on the futures tape. Gexbot nodes are index strikes on a converted ruler. Map through the basis; expect a few points of offset. Overnight structure has no State leftover at 09:30.

Futures-tape delta (who is lifting or hitting ES or NQ) is **not** Gexbot DEX. Do not add them. A futures print is never “the dealer.”

Use plain tape words. Never import a charting methodology’s named levels or setups as if they were Gexbot objects.

## Full-book vanna/charm vs residual-only

Pinning literature usually uses the whole OI vault. Gexbot’s −vanna / charm ladders are **beta** and applied to **today’s classified residual only**. Last-hour family. Not a morning object.
