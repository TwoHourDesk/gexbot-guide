# Distinctions

Chapters apply one cousin family at a time. This page is the spine: every family this book names, the Gexbot cut, and the import mistake, with the chapter that owns it. Contrast families of measurement, not competing trade systems. A well-known tool may be named once so you can place the family. Never import that tool’s named levels or setups.

The first block is the families — including the later ones Chapter 1 does not own (residual-only vanna/charm, named session methodologies, public GEX papers, strategy-first courses). The second is every taught object that carries those same three fields. A reader who has sat the chapters still gets the grouping: which objects refuse the same cousin.
