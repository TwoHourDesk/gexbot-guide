Intraday walls that matter for the open are usually **latest**. Full is overnight context. Mixing full-book zero gamma with a 0DTE scalp is a misread.

## What you may claim next to a futures tape

**Observed:** a Gexbot residual node at a converted strike.  
**Inferred:** a dealer hedge *may* land in ES or NQ in that share-equivalent.  
**Never:** “that ES print *is* the dealer hedge.”

NDX options are a thinner book than SPX. Treat NQ reads as weaker evidence (*inferred*).

## Transfer rules

- SPX docs folklore (+GEX OF as local top in a quiet short-gamma tape) does **not** automatically apply to NQ. Rename the claim if you use it.
- SPY is described as more directional than SPX. ES is converted SPX, not SPY.
- When VIX > 20, docs say SPX starts trading like SPY (*folklore*). That sentence is still an SPX sentence.

## Running example

Same 500 ATM contracts, Δ 0.50, $25,000/pt.

- If they are **SPX** calls: ≈ **500 ES**. Print is SPX; hedge venue is ES.
- If they are **NDX** calls: $25,000 / $20 ≈ **1,250 NQ**. Print is NDX; hedge venue is NQ. **1 ATM NDX ≈ 2.5 NQ.**

## Summary

The information layer sits *beside* NQ and ES. The option residual is not the futures tape. Conversion is a multiplier, not aggressor truth.

## Newcomer questions

1. **Does Gexbot show ES volume?** No. `ES_SPX` is converted SPX options.
2. **Is 1 SPX option 1 ES?** ATM, as a toy: 1 ATM SPX ≈ 1 ES of delta (*market-general*).
3. **Can I copy an SPX local-top read onto NQ?** Only if you rename the claim. NDX is thinner (*inferred*).
